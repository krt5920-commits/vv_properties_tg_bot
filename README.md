## 1. Создание бота в Telegram через BotFather

Для начала вам нужно создать своего бота в Telegram и получить уникальный токен.

1.  **Откройте BotFather**: В приложении Telegram найдите пользователя `@BotFather` и начните с ним чат. Это официальный бот для управления другими ботами.

2.  **Начните создание нового бота**: Отправьте команду `/newbot` в чат с BotFather.

3.  **Придумайте имя для бота**: BotFather попросит вас ввести имя для вашего бота. Это имя будет отображаться в списке контактов и чатах. Например, "UAE Real Estate Bot" или "Dubai Properties Assistant". Введите желаемое имя и отправьте его.

4.  **Придумайте username для бота**: Теперь BotFather попросит вас придумать уникальный username для вашего бота. Username должен заканчиваться на "bot" (например, `UAERealEstate_bot` или `DubaiPropertiesAssistantBot`). Этот username будет использоваться для поиска вашего бота в Telegram. Введите желаемый username и отправьте его.

5.  **Получите токен**: После успешного создания имени и username, BotFather пришлет вам сообщение с подтверждением и **токеном вашего бота**. Токен выглядит как длинная строка символов (например, `123456789:ABCDEF-1234567890abcdef1234567890`). **Обязательно скопируйте этот токен и сохраните его в надежном месте.** Он понадобится вам для запуска бота.

    *Пример сообщения от BotFather:*
    ```
    Done! Congratulations on your new bot. You will find it at t.me/YourBotUsername. You can now add a description, about section and profile picture for your bot, see /help for a list of commands.

    Use this token to access the HTTP API:
    123456789:ABCDEF-1234567890abcdef1234567890

    For a description of the Bot API, see this page: https://core.telegram.org/bots/api
    ```

## 2. Как узнать свой OWNER_CHAT_ID

`OWNER_CHAT_ID` — это уникальный идентификатор вашего личного чата в Telegram. Бот будет отправлять вам уведомления о новых заявках на встречу именно по этому ID.

1.  **Откройте @userinfobot или @getmyid_bot**: В приложении Telegram найдите одного из этих ботов (например, `@userinfobot`) и начните с ним чат.

2.  **Получите свой Chat ID**: Отправьте боту любое сообщение (например, `/start` или просто "Привет"). В ответ бот пришлет вам информацию, среди которой будет ваш `ID` или `Chat ID`. Это числовой идентификатор (например, `123456789`).

3.  **Скопируйте и сохраните ID**: Скопируйте это число и сохраните его. Оно понадобится вам при настройке бота.

## 3. Получение OpenAI API ключа

Бот использует искусственный интеллект OpenAI GPT для ведения свободного диалога. Для этого вам понадобится API ключ от OpenAI.

1.  **Зайдите на платформу OpenAI**: Откройте веб-сайт [platform.openai.com](https://platform.openai.com/) в вашем браузере.

2.  **Войдите или зарегистрируйтесь**: Если у вас уже есть аккаунт OpenAI, войдите в него. Если нет, зарегистрируйтесь. Возможно, потребуется привязать номер телефона и платежную карту (для использования API взимается плата, но для небольших объемов использования она минимальна).

3.  **Создайте новый секретный ключ**: После входа в аккаунт, перейдите в раздел "API keys" (обычно находится в меню слева или в вашем профиле). Нажмите кнопку "Create new secret key" (Создать новый секретный ключ).

4.  **Скопируйте ключ**: Вам будет показан новый секретный ключ (начинается с `sk-`...). **Обязательно скопируйте его сразу, так как он будет показан только один раз.** Сохраните этот ключ в надежном месте. Он также понадобится для настройки бота.

## 4. Развертывание бота на Render (бесплатный план)

Render — это облачная платформа, которая позволяет бесплатно размещать небольшие приложения. Мы будем использовать ее для запуска вашего Telegram-бота.

1.  **Загрузите код бота на GitHub**: Для развертывания на Render вам нужно будет разместить файлы вашего бота в репозитории GitHub. Если у вас нет аккаунта GitHub, зарегистрируйтесь на [github.com](https://github.com/).
    *   **Создайте новый репозиторий**: На главной странице GitHub нажмите кнопку "New" (Новый) или "Create repository" (Создать репозиторий).
    *   **Назовите репозиторий**: Придумайте имя для вашего репозитория, например, `telegram-uae-bot`. Выберите опцию "Private" (Приватный), чтобы ваш код был доступен только вам. Нажмите "Create repository".
    *   **Загрузите файлы**: После создания репозитория вы увидите страницу с инструкциями. Найдите опцию "uploading an existing file" (загрузка существующего файла) или просто перетащите файлы `main.py`, `requirements.txt`, `README.md`, `Procfile` и `.env.example` из папки вашего бота прямо в окно браузера на странице репозитория. Нажмите "Commit changes" (Зафиксировать изменения).

2.  **Регистрация на Render**: Откройте [render.com](https://render.com/) в браузере. Зарегистрируйтесь, используя свой аккаунт GitHub (рекомендуется) или адрес электронной почты.

3.  **Создайте новый Background Worker**: После входа в Render, на панели управления (Dashboard) нажмите кнопку "New" (Новый) и выберите "Background Worker" (Фоновый рабочий процесс). Мы выбираем Background Worker, так как наш бот использует Long Polling и не требует HTTP-сервера.

4.  **Подключите репозиторий GitHub**: Render попросит вас подключить ваш аккаунт GitHub. Разрешите доступ к репозиторию, который вы создали для бота (например, `telegram-uae-bot`).

5.  **Настройте параметры Worker**:
    *   **Name (Имя)**: Придумайте имя для вашего сервиса, например, `uae-bot-worker`.
    *   **Region (Регион)**: Выберите ближайший к вам регион (например, `Frankfurt (Germany)` или `Ohio (USA)`).
    *   **Branch (Ветка)**: Оставьте `main` (или `master`, если вы так назвали основную ветку).
    *   **Root Directory (Корневая директория)**: Оставьте пустым, если ваш код находится в корне репозитория.
    *   **Runtime (Среда выполнения)**: Выберите `Python 3`.
    *   **Build Command (Команда сборки)**: Введите `pip install -r requirements.txt`.
    *   **Start Command (Команда запуска)**: Введите `python3.11 main.py`.
    *   **Instance Type (Тип экземпляра)**: Выберите `Free` (Бесплатный).

6.  **Настройте переменные окружения (Environment Variables)**:
    Это очень важный шаг. Вам нужно добавить переменные, которые бот использует для работы.
    Нажмите "Advanced" (Дополнительно) и затем "Add Environment Variable" (Добавить переменную окружения) для каждой из следующих:
    *   **Key**: `TELEGRAM_BOT_TOKEN`
        **Value**: `[Ваш токен от BotFather]` (вставьте токен, который вы получили в Шаге 1)
    *   **Key**: `OPENAI_API_KEY`
        **Value**: `[Ваш API ключ от OpenAI]` (вставьте ключ, который вы получили в Шаге 3)
    *   **Key**: `OPENAI_API_BASE`
        **Value**: `https://api.openai.com/v1` (вставьте это значение как есть)
    *   **Key**: `OWNER_CHAT_ID`
        **Value**: `[Ваш Chat ID]` (вставьте ваш ID, который вы получили в Шаге 2)

7.  **Разверните (Deploy)**: После того как все переменные добавлены, нажмите кнопку "Create Background Worker" (Создать фоновый рабочий процесс). Render начнет развертывание вашего бота. Это может занять несколько минут.

    Вы можете следить за процессом в разделе "Logs" (Логи). Если все настроено правильно, вы увидите сообщение "Bot started with long polling..." в логах, что означает, что ваш бот успешно запущен.

## 5. Альтернативное развертывание на Railway

Railway — еще одна платформа, похожая на Render, которая также предлагает бесплатный план. Если у вас возникли проблемы с Render, можете попробовать Railway.

1.  **Загрузите код бота на GitHub**: Убедитесь, что ваш код бота уже загружен в приватный репозиторий GitHub, как описано в Шаге 4.1.

2.  **Регистрация на Railway**: Откройте [railway.app](https://railway.app/) в браузере. Зарегистрируйтесь, используя свой аккаунт GitHub.

3.  **Создайте новый проект**: После входа в Railway, нажмите "New Project" (Новый проект) и выберите "Deploy from GitHub Repo" (Развернуть из репозитория GitHub).

4.  **Подключите репозиторий**: Выберите ваш репозиторий с ботом (например, `telegram-uae-bot`).

5.  **Настройте переменные окружения**: Перейдите в раздел "Variables" (Переменные) вашего нового сервиса. Добавьте те же переменные окружения, что и для Render:
    *   `TELEGRAM_BOT_TOKEN`
    *   `OPENAI_API_KEY`
    *   `OPENAI_API_BASE` (значение `https://api.openai.com/v1`)
    *   `OWNER_CHAT_ID`

6.  **Настройте команду запуска**: Перейдите в раздел "Settings" (Настройки) вашего сервиса. В поле "Start Command" (Команда запуска) введите `python3.11 main.py`.

7.  **Разверните**: Railway автоматически начнет развертывание после настройки. Вы можете отслеживать прогресс в логах.

## 6. Проверка работы бота

После успешного развертывания бота на Render или Railway, пришло время его протестировать.

1.  **Найдите бота в Telegram**: Откройте Telegram и введите username вашего бота (тот, что заканчивается на `_bot`) в строке поиска.

2.  **Начните диалог**: Нажмите на бота и отправьте команду `/start`.

3.  **Проверьте сценарии**: 
    *   Нажмите кнопку "🏡 My personal properties" / "🏡 Мои личные объекты". Бот должен прислать ссылку на Google Sheet.
    *   Нажмите кнопку "🌴 Arabian Hills Estate". Бот должен прислать описание проекта и ссылку на Google Drive.
    *   Попробуйте задать боту вопросы, связанные с недвижимостью в ОАЭ, чтобы проверить работу OpenAI GPT.
    *   Попробуйте указать время встречи или контактные данные. Бот должен ответить "Great, I\'ll confirm with the owner and get back to you." (или русскую версию) и отправить вам (владельцу) уведомление в Telegram.

## 7. Как обновить тексты в будущем

Все тексты, которые бот использует для общения, хранятся в файле `main.py`.

1.  **Откройте файл `main.py`**: Вам нужно будет отредактировать этот файл в вашем репозитории GitHub.

2.  **Найдите раздел `BOT_TEXTS`**: Примерно в строке 30 (может немного отличаться) вы найдете словарь `BOT_TEXTS`. В нем содержатся все фразы на английском (`"en"`) и русском (`"ru"`) языках.

    ```python
    # Texts for the bot (English and Russian)
    BOT_TEXTS = {
        "en": {
            "start_greeting": "Hello! I can help you with real estate in the UAE. What would you like to know about?",
            # ... другие тексты
        },
        "ru": {
            "start_greeting": "Привет! Я могу помочь вам с недвижимостью в ОАЭ. Что бы вы хотели узнать?",
            # ... другие тексты
        }
    }
    ```

3.  **Отредактируйте тексты**: Аккуратно измените нужные вам фразы, сохраняя структуру словаря. **Будьте внимательны с кавычками и специальными символами (`\n` для новой строки).**

4.  **Сохраните изменения и обновите репозиторий**: После редактирования сохраните файл и загрузите обновленную версию в ваш репозиторий GitHub. Render (или Railway) автоматически обнаружит изменения и перезапустит вашего бота с новыми текстами.

## 8. Что делать, если бот не отвечает

Если ваш бот перестал отвечать или работает некорректно, вот несколько шагов для диагностики:

1.  **Проверьте логи на Render/Railway**: На панели управления Render или Railway найдите ваш сервис (worker) и перейдите в раздел "Logs" (Логи). Здесь вы увидите все сообщения и ошибки, которые генерирует ваш бот. Внимательно изучите последние записи. Красные строки обычно указывают на ошибки.

2.  **Частые проблемы и их решения**:
    *   **Бот не запускается вообще**: 
        *   **Неправильный `TELEGRAM_BOT_TOKEN`**: Убедитесь, что вы правильно скопировали токен от BotFather и вставили его в переменную окружения `TELEGRAM_BOT_TOKEN` без лишних пробелов.
        *   **Неправильный `OPENAI_API_KEY`**: Аналогично, проверьте ключ OpenAI.
        *   **Ошибка в `requirements.txt` или `Procfile`**: Убедитесь, что команды сборки и запуска на Render/Railway указаны точно так, как в инструкции.
    *   **Бот запускается, но не отвечает на сообщения**: 
        *   **Неправильный `TELEGRAM_BOT_TOKEN`**: Возможно, токен недействителен или был отозван. Попробуйте сгенерировать новый токен через BotFather и обновить переменную окружения.
        *   **Проблемы с сетью на хостинге**: Иногда бывают временные сбои на стороне Render/Railway. Попробуйте перезапустить сервис.
    *   **Бот не использует GPT или выдает ошибку при диалоге**: 
        *   **Неправильный `OPENAI_API_KEY`**: Проверьте ключ OpenAI. Возможно, он недействителен или у вас закончились средства на аккаунте OpenAI.
        *   **Проблемы с доступом к OpenAI API**: Убедитесь, что `OPENAI_API_BASE` установлен правильно (`https://api.openai.com/v1`).
    *   **Бот не отправляет уведомления владельцу**: 
        *   **Неправильный `OWNER_CHAT_ID`**: Убедитесь, что вы правильно указали свой `OWNER_CHAT_ID`. Бот должен быть запущен, и вы должны были начать с ним диалог, чтобы он мог отправить вам сообщение.
        *   **Бот не может найти ваш чат**: Убедитесь, что вы начали диалог с ботом в Telegram, прежде чем ожидать от него уведомлений.

Если вы не можете решить проблему самостоятельно, скопируйте последние логи и обратитесь за помощью к специалисту.
